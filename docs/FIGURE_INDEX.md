# Figure provenance and slide mapping

Each figure below is generated by `figures/plot_all.py` from the exact raw CSV shown in the next column. PNG and SVG versions are in `results/figures/`; PNG files are embedded in PowerPoint.

| Figure | Raw input | PowerPoint slide | Interpretation |
|---|---|---:|---|
| `fig01_rsa_order_qft` | `rsa_qft_histogram.csv` | 28 | Ideal Shor order-finding, N=15, six counting qubits |
| `fig02_ecc_dlog_qft` | `ecc_qft_histogram.csv` | 29 | Ideal ECC discrete-log Fourier sampling, group order 19 |
| `fig03_grover_success` | `grover_probability.csv` | 30 | Ideal quantum search versus classical distinct guesses |
| `fig04_kem_latency` | `primitive_summary.csv` | 34 | OpenSSL CLI wall clock (not intrinsic primitive latency) |
| `fig05_signature_latency` | `primitive_summary.csv` | 35 | Same CLI measurement path, log scale; distinct security strengths |
| `fig06_signature_sizes` | `sizes.csv` | 35 | Public-key SPKI DER and signature bytes |
| `fig07_kem_bytes` | `sizes.csv` | 34 | Serialized keys and ML-KEM ciphertext (not TLS wire overhead) |
| `fig08_aes_throughput` | `aes_summary.csv` | 36 | In-process AES-GCM within the same Python binding |
| `fig09_results_triptych` | `sizes.csv` | 33 | Exact bytes for ML-KEM ciphertext, ML-DSA and SLH-DSA signatures |

Additional equations in slides 7-24 are typeset from `slides/assets/equations/*.tex`, including security-assumption and K-PKE/ML-DSA intuition. Formula PNG/PDF assets are generated by `figures/make_equations.py`, not from invented measurements.
